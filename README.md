# Simon Snake

A mobile-first snake game for the browser, written in plain JavaScript with no dependencies.

## Play

Open `index.html` in a browser, or serve the folder with any static server:

```sh
npx serve .   # or: python3 -m http.server
```

## Controls

- **Swipe** anywhere on the screen to steer. One long swipe can make several turns.
- **D-pad** buttons under the board.
- **Keyboard:** arrow keys or WASD. Space or P pauses.
- **❚❚** pauses and resumes. The game also pauses by itself when you switch apps.
- **Walls / Wrap** switches between hitting the walls and wrapping around the edges. You can change it between games.

The snake speeds up with every apple. Your best score is saved on the device.
